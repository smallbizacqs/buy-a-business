# Lender package checklist (preparation)

The lender's own checklist governs: get it first and map it onto this list. Use the lender's forms (including SBA forms), never copies found online. Items marked with a source id rest on SOP 50 10 8.1 (see `sba-facts.md`); the rest are items lenders commonly ask for.

Write each item into the tracker as area `lender`, id `B01`…, with owner and a due date from the timeline.

## About the buyer

| Item | Owner | Notes |
|---|---|---|
| Personal financial statement on the lender's form, dated within 90 days, for each 20%+ owner and guarantor | buyer | Source `sba-sop-50-10-8-1-owner-financial-statement` |
| SBA Form 1919: a separate one for each co-borrower, completed and signed by the applicant's authorized representative, on the lender's copy (only if there are co-borrowers) | buyer | Source `sba-sop-50-10-8-1-form-1919` |
| Personal federal tax returns, last 3 years (lender will say how many) | buyer | |
| Resume focused on management and industry experience, and who will run day-to-day operations | buyer | The credit memo describes this (source `sba-sop-50-10-8-1-management-experience`) |
| Source of equity: bank and brokerage statements showing the funds and how long they've been there; gift letters; retirement-plan documents if used | buyer | Equity rules: sources `sba-sop-50-10-8-1-equity-minimum`, `-equity-unlimited-sources`, `-equity-limited-sources` |
| Credit report authorization; ID | buyer | |
| Entity documents for the buyer's acquiring company | buyer / lawyer | In an asset purchase, the acquiring company is the borrower (source `sba-sop-50-10-8-1-asset-purchase-borrower`) |
| Business plan: why this business, buyer's plan for the first year, transition plan, management | buyer | Short and specific |
| Projections (first 2 to 3 years) with assumptions | buyer | Evaluated, but not relied on for coverage (source `sba-sop-50-10-8-1-projections`) |
| Debt schedule for any other businesses the buyer owns | buyer | Global cash flow (source `sba-sop-50-10-8-1-global-cash-flow`) |

## Ordered by the lender (track, don't order)

- Business valuation (ordered by and for the lender: source `sba-sop-50-10-8-1-valuation-for-lender`).
- Site visit (source `sba-sop-50-10-8-1-site-visit`).
- Lien, judgment and tax searches; real estate appraisal and environmental reports where applicable.

## Before closing (from the commitment letter)

- Insurance binders: hazard, liability and any life insurance the lender requires (source `sba-sop-50-10-8-1-insurance-credit-memo`).
- Equity injection in place and documented.
- Signed standby agreement for any seller note counted as equity.
- Landlord consent or new lease.
- Payoff letters for the seller's debts.
- Everything else in the credit memo conditions (source `sba-sop-50-10-8-1-conditions-before-disbursement`); see `small-business-closing-checklist`.
