# Operator model worksheets

## 1. Role inventory

Ask the seller (through the user) to walk through a normal week and a busy week. Fill one row per role.

| Role | What it involves | Owner hours/week | Could a current employee do it? | Owner-operator plan | Manager plan |
|---|---|---|---|---|---|
| Selling and estimating | Quotes, closing new work, pricing | | | | |
| Key customer relationships | The accounts that would leave with the owner | | | | |
| Scheduling and dispatch | Who goes where, daily | | | | |
| Hiring, firing, payroll | Recruiting, reviews, discipline | | | | |
| Licensed or technical work | Work only a license holder may do or sign | | | | |
| Purchasing and suppliers | Pricing, terms, key supplier relationships | | | | |
| Books and cash | Invoicing, collections, bills, bank | | | | |
| Compliance | Permits, insurance, safety, regulators | | | | |
| Fixing what breaks | Equipment, angry customers, no-shows | | | | |

Red flags: the owner holds the license the business operates under; the owner is the main salesperson; customer relationships are personal to the owner; no one else can price a job.

Then:

| Line | Owner-operator | Manager-led |
|---|---|---|

## 3. Ready to run without the owner? (12 questions)

Score yes or no; "don't know" counts as no until the seller shows evidence.

1. A manager or lead has run day-to-day operations for at least a year, and is staying.
2. The owner works fewer than about 20 hours a week in the business today.
3. No single customer is reached only through the owner.
4. Someone other than the owner prices and sells work.
5. Any license the business needs can be held by an employee or a new manager (a lawyer confirms the rule for the trade and state).
6. Written procedures exist for the core jobs.
7. Monthly financial statements are produced on time by someone other than the owner.
8. The business tracks a few numbers weekly (sales, jobs, margin, cash, backlog).
9. Employee turnover is low and pay is at market.
10. The owner has taken a two-week vacation recently without the business slipping.
11. Systems (scheduling, CRM, accounting) are in software, not in the owner's head.
12. The business makes enough to pay a full manager and still cover debt with a cushion.

- 11 to 12: ready for manager-led ownership from close, with oversight.
- 9 to 10: plan to operate for a transition period while the gaps close.
- Under 9: an owner-operator business. Manager-led only after you build what's missing.

## 4. First-year time budget

| Period | Owner-operator hours/week | Manager-led owner hours/week | What fills the time |
|---|---|---|---|
| Months 0 to 3 (seller transition) | | | Learning the business, meeting every employee and top customer, no big changes |
| Months 4 to 6 | | | Fixing the first problems, hiring gaps |
| Months 7 to 12 | | | Settling routines, first improvements |

Ask the user to fill hours from the role inventory, not from hope. If the seller's help is part of the plan and the loan is an SBA 7(a) initial acquisition, SOP 50 10 8.1 says the seller may not stay as an officer, director, owner or employee, but the business may hire the seller as a consultant "for a period not to exceed 24 months (in aggregate, including any extensions)" (`sba-sop-50-10-8-1-seller-consultant`; check its `review_by` date). Plan the handover inside that window. Note that most buyers find the first months heavier than planned, whatever the model.

## 5. KPIs that trigger a switch to manager-led

Write two or three, measured monthly, held for two quarters: revenue within plan, gross margin stable, cash above a floor, no loss of a top-10 customer, manager hitting their own targets.
